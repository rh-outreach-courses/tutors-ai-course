## Scope of this AI Course

### Core Values

**Local**: We emphasize the importance of running AI models and experiments locally whenever possible to reduce reliance on external services and improve user control.

**Private**: Respect and prioritize user data privacy by ensuring that all projects and tools adhere to best practices for data protection. This is also why we emphasize local usage.

**Open Source**: Leverage open-source tools, frameworks, and datasets to promote accessibility, community collaboration, and transparent learning experiences.

### Course Goals

**Critical Thinking**: Teach you to evaluate the ethical implications of AI systems, including bias, fairness, and societal impact.

**Hands-On Coding**: Focus on practical, project-based learning.


### Course non-goals

**Comprehensive Understanding**: This course only scratches the surface of AI. It does not provide students with complete knowledge of AI, machine learning, deep learning, and natural language processing (NLP).

### Practicality and Flexibility
While the course promotes local, private, and open-source solutions, it acknowledges the value of proprietary tools for specific applications. For instance:

* Using OpenAI APIs to quickly learn about prompts.
* Leveraging cloud-based tools for experiments.

By combining open-source fundamentals with pragmatic exposure to proprietary solutions, the course aims to prepare you for real-world AI challenges while staying true to its core values.

### Target Audience

This course is designed for individuals with a technical background who are:
* New to AI and machine learning.
* Interested in ethical and privacy-respecting AI practices.
* Keen to work on practical projects and build an understanding of AI tools.
