# InstructLab

## What is InstructLab?

InstructLab is a core element of Red Hat Enterprise Linux AI. It's an open source community project that provides a simpler and more accessible way to improve a large language model (LLM) used in generative artificial intelligence (gen AI) applications.

Launched by Red Hat and IBM at the 2024 Red Hat Summit, InstructLab not only brings a truly open source development model to LLMs, but it also gives people with minimal technical experience a way to contribute to AI model development and continual improvement.

Here’s a video that goes into further detail on what InstructLab is:

[What is InstructLab?](https://www.redhat.com/en/blog/what-is-instructlab)
