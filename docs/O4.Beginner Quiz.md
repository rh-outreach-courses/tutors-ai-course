# Quiz 1

## Chapter 1: Exploration vs. Exploitation in AI

**Question 1:** What is the primary focus of the exploration vs. exploitation trade-off?  
A) Selecting the most expensive model  
B) Balancing between testing new models and using the best-performing model  
C) Avoiding any model testing  
D) Using only one model forever  
<details>
  <summary>Reveal answer</summary>
  Correct Answer: B) Balancing between testing new models and using the best-performing model.
</details>

---

**Question 2:** What does the ε-greedy algorithm help with?  
A) Ensuring all models are used equally  
B) Balancing exploration and exploitation  
C) Generating random outputs  
D) Reducing computation time  
<details>
  <summary>Reveal answer</summary>
  Correct Answer: B) Balancing exploration and exploitation.
</details>

---

**Question 3:** Which model had the highest average score after the initial trials?  
A) GPT-3  
B) BERT  
C) GPT-3.5  
D) All models had the same score  
<details>
  <summary>Reveal answer</summary>
  Correct Answer: C) GPT-3.5.
</details>

**Question 4:** Why is it important to consider exploration in model selection?  
A) It helps save time.  
B) It can lead to discovering better-performing models.
